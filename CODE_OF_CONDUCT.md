# Code of Conduct

## Expected conduct

Project participants must:

- communicate with respect and patience;
- discuss the work, not a person's identity or character;
- accept constructive feedback and correct mistakes;
- make room for people with different backgrounds and experience; and
- protect private information shared during support or review.

## Unacceptable conduct

The project does not permit harassment, discrimination, threats, sexualized
attention, sustained disruption, personal attacks, or publication of another
person's private information without permission.

## Scope

This policy applies to repository issues, pull requests, discussions, review
comments, and other spaces where a person represents Nicos Catalog.

## Reporting

For a private report, use the repository's GitHub Security Advisory flow and
start the title with `Conduct report`. Do not put private catalog data in the
report. Use GitHub's abuse-reporting tools for conduct that also violates
GitHub policy.

Maintainers will limit report access to the people who need it. A maintainer
who is named in a report must not make the enforcement decision.

## Enforcement

Maintainers can edit or remove content, give a warning, limit participation,
or permanently remove a participant. The response must be proportionate to
the conduct, prior behavior, impact, and risk of recurrence. Retaliation
against a person who makes a good-faith report is not permitted.
