# Support

Nicos Catalog does not use GitHub Issues for support, feedback, or backlog
management.

Use the [documentation](docs/README.md) and
[troubleshooting guide](site/src/content/docs/troubleshooting.md) first. If you
can provide a minimal source or documentation correction, open a pull request.
Include a synthetic or fully redacted reproduction. Do not include secrets,
private catalog values, or local absolute paths.

Report a vulnerability through a
[private GitHub Security Advisory](https://github.com/nstranquist/nicos-catalog/security/advisories/new).
Do not report a vulnerability in a pull request or another public post.
