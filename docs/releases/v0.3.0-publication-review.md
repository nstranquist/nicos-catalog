# Nicos Catalog v0.3.0 publication review

Review date: 2026-08-20.

## Verdict

`v0.3.0` is public and installable through the Go module proxy. The public tag,
GitHub Release, CI runs, proxy response, and installed binary all exist.

The review found two release-integrity defects:

- The public tag is annotated but not signed.
- The GitHub Release body still contains pre-publication status text and lists
  completed publication steps as pending.

Do not replace or move the public tag. Correct the Release body in place after
an operator approves the external edit. Require a verified signature on future
release tags.

## Lifecycle boundary

This evidence proves a public source repository, a public release, and module
distribution. It does not prove these later states:

- a hosted Explorer deployment.
- an announcement or launch campaign.
- independent v0.3 adoption.
- active use or retention.
- revenue.

No hosted deployment or independent v0.3 adoption receipt was present in the
review evidence.

## Approved remediation

An authorized operator can replace the stale GitHub Release body with the
timeless release notes:

```sh
gh release edit v0.3.0 \
  --repo nstranquist/nicos-catalog \
  --notes-file docs/releases/v0.3.0.md
```

After the edit, read the Release again and compare its body with the file. Do
not change the tag target. Publish the implementation and documentation fixes
as a new patch release. Before the operator pushes the new tag, sign and verify
it.
