# Nicos Catalog v0.3.2 publication review

Review date: 2026-08-20.

## Verdict

`v0.3.2` is public, released, proxy-installable, and deployed as a synthetic
static Explorer. The release, distribution, and deployment inputs all trace to
commit `0f6b56d72b14aa875ec91acca244151e7a3abecb`.

This patch repairs two stale README fragments in the public portfolio manifest
and adds a publication regression test. It does not change the Go API, index
schema, Explorer contract, runtime behavior, or security boundary.

The annotated tag has a valid SSH signature under the repository-owned signer
policy. GitHub reports `unknown_key` because the account has not registered the
key as a signing key. This missing account badge does not invalidate the
independently verified signature. This review does not claim account-identity
verification.

## Defects found and repaired

- The `v0.3.1` portfolio manifest linked to the retired `five-minute-smoke`
  README fragment in two places. The links now name the current Explorer and
  authored-catalog headings.
- Publication tests did not check GitHub fragments in portfolio metadata. The
  new test parses the manifest and validates each repository-local fragment
  against the README headings.
- A local performance sample ran beside CPU-heavy fuzz workers and exceeded
  its latency limits. The result was rejected. The release runbook now requires
  an isolated sample and forbids a baseline change for host contention.

## Evidence boundaries at review time

The review did not observe an account-level signing identity, an audible
VoiceOver or NVDA review, or independent adoption. These are evidence states,
not implementation backlog. Synthetic proof cannot establish them. The public
issue tracker was retired in v0.3.3.

## Lifecycle boundary

This review proves public source, release, proxy distribution, and a hosted
synthetic deployment. It does not establish an announcement, launch,
independent adoption, active use, retention, or revenue.
