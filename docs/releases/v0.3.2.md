# Nicos Catalog v0.3.2

## Main result

Nicos Catalog v0.3.2 is a compatible metadata-integrity patch. It repairs two
stale README links in the public portfolio manifest and adds a regression test
for repository-local GitHub fragments.

## Fixed

- The Explorer evidence link now names the `Five-minute Explorer` README
  heading.
- The authored-catalog evidence link now names the `Start an authored catalog`
  README heading.
- The publication test now parses the portfolio manifest and checks each
  repository-local GitHub fragment against the README heading anchors.

## Compatibility

- The module and CLI remain pre-1.0 SemVer.
- No exported Go API changed.
- `Index.SchemaVersion` remains 2.
- Explorer API and static manifest `schema_version` remain 1.
- Existing v0.3.0 and v0.3.1 indexes remain valid.
- Runtime and security behavior are unchanged from v0.3.1.

## Security properties

The v0.3.1 boundaries remain in force: loopback-only live serving, a closed
public projection for static export, fixed response limits, no third-party
Explorer requests, and no write command in HTTP or MCP.

These notes describe release content. A dated publication review on the main
branch records public distribution, deployment, and residual risks after the
release is published.

## Install

```sh
go install github.com/nstranquist/nicos-catalog/cmd/nicos-catalog@v0.3.2
nicos-catalog version --expect v0.3.2
```
