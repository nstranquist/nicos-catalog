# Nicos Catalog v0.3.3 publication review

Review date: 2026-08-20.

## Verdict

`v0.3.3` is public, released, proxy-installable, and deployed as a synthetic
static Explorer. The release, distribution, and deployment inputs trace to
commit `58bc48ffe4c6a14c296381d1f05dc46038ced8b1`.

This patch hardens static Explorer deployments, retires GitHub Issues as a
support and backlog surface, repairs lifecycle language, expands dependency
update coverage, and adds publication regression tests. It does not change the
Go API, index schema, Explorer data contract, or loopback-only live-server
boundary.

The annotated tag has a valid SSH signature under the repository-owned signer
policy. GitHub reports `unknown_key` because the account has not registered the
key as a signing key. This missing account badge does not invalidate the
independently verified signature. This review does not claim account-identity
verification.

## Findings repaired

- Static deployments had no repository-defined response-header policy. The
  exporter now emits a deterministic `_headers` control file with Content
  Security Policy, frame denial, MIME protection, referrer, cross-origin, and
  browser-feature restrictions.
- Hosting guidance treated a public URL plus a verified journey as launch
  evidence. The guidance now limits that proof to a hosted deployment.
- Public Issue forms remained from v0.3.1. The forms and repository Issue
  capability are removed. `SUPPORT.md`, private security reporting, and
  reviewed pull requests define the public paths.
- Dependabot did not cover the active Go, GitHub Actions, Explorer, and site
  dependency roots. It now covers all four.
- Publication tests did not prevent these regressions. The suite now rejects
  public Issue surfaces, Issue feedback links, incomplete dependency-manager
  coverage, missing support boundaries, and weakened lifecycle wording.

## Repository controls

- GitHub Issues and Discussions are disabled. No public Issue is an active
  support, feedback, or backlog item.
- The three former open Issues were closed as not planned when the public
  tracker was retired. Their closure records do not claim implementation.
- Vulnerability alerts, Dependabot security updates, secret scanning, and push
  protection are enabled.
- The main ruleset rejects deletion and non-fast-forward updates, requires
  linear history, and requires the publication-critical CI checks.
- The `v*` tag ruleset rejects release-tag deletion and non-fast-forward
  updates.

## Evidence boundaries at review time

The review did not observe an account-level signing identity, an audible
VoiceOver or NVDA review, or independent adoption. These are evidence states,
not implementation backlog. Synthetic proof cannot establish them. Future
evidence may be recorded when it exists; no public task is open for it.

## Lifecycle boundary

This review proves public source, release, proxy distribution, and a hosted
synthetic deployment. It does not establish an announcement, launch,
independent adoption, active use, retention, or revenue.
