# Nicos Catalog v0.3.3

## Main result

Nicos Catalog v0.3.3 is a compatible publication-safety patch. Static Explorer
exports now carry restrictive response-header policy. The repository also
retires GitHub Issues as a support and backlog surface.

## Added

- Each static Explorer export includes a deterministic Cloudflare Pages
  `_headers` control file.
- The control file applies Content Security Policy, frame denial, MIME
  protection, referrer, cross-origin, and browser-feature restrictions.
- `SUPPORT.md` and the pull request template define the public contribution,
  privacy, and private security-reporting paths.
- Dependabot covers the Go module, GitHub Actions, Explorer pnpm project, and
  documentation pnpm project.
- A repository-owned Code of Conduct defines expected behavior, private
  reporting, and proportionate enforcement.

## Fixed

- Hosting guidance no longer treats a public URL and synthetic browser proof
  as evidence of a launch.
- Publication tests reject a restored public issue tracker, a portfolio
  feedback link to it, missing dependency-manager coverage, and weakened
  launch-evidence wording.
- Product metadata records the synthetic Explorer as deployed. It does not
  claim a launch or independent adoption.

## Compatibility

- The module and CLI remain pre-1.0 SemVer.
- No exported Go API changed.
- `Index.SchemaVersion` remains 2.
- Explorer API and static manifest `schema_version` remain 1.
- Existing v0.3.x indexes remain valid.
- Static hosts that ignore `_headers` keep serving the same application and
  data files. They must apply equivalent security headers themselves.

## Security properties

The established boundaries remain in force: loopback-only live serving, a
closed public projection for static export, fixed response limits, no
third-party Explorer requests, and no write command in HTTP or MCP. Cloudflare
Pages deployments now apply the export's restrictive header policy to static
responses.

These notes describe release content. A dated publication review on the main
branch records public distribution, deployment, and residual evidence states
after the release is published.

## Install

```sh
go install github.com/nstranquist/nicos-catalog/cmd/nicos-catalog@v0.3.3
nicos-catalog version --expect v0.3.3
```
