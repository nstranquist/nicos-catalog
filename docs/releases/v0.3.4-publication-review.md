# Nicos Catalog v0.3.4 publication review

Review date: 2026-08-21.

## Verdict

`v0.3.4` is public, released, proxy-installable, and deployed as a synthetic
static Explorer. The release and public distribution inputs trace to commit
`d0e1aa51bd6ab0510ed360bf08b5ae1f2989230e`. The Worker and retained Pages
deployment both serve the exact static export from that release.

This patch closes the maintenance work that followed `v0.3.3`. It updates the
supported dependency set, rebuilds the embedded Explorer, and adds the
documentation site to public continuous integration. It does not change the Go
API, index schema, Explorer data contract, or loopback-only live-server
boundary.

The annotated tag has a valid SSH signature under the repository-owned signer
policy. GitHub reports `unknown_key` because the account has not registered the
key as a signing key. This review does not claim account-identity verification.

## Findings repaired

- The combined dependency update changed the embedded Explorer after the
  `v0.3.3` release. The maintained source is now published as the SemVer patch
  `v0.3.4`.
- The Worker endpoint served stale documentation instead of the current
  Explorer. It now uses an assets-only binding and serves the exact `v0.3.4`
  export.
- A deployment proof could accept any public HTTP 200 response immediately
  after a deploy. The private deployment tool now binds public proof to the
  exact exported `index.html` body and retries while stale content remains.
- The Pages project is redeployed from the same export and retained as an
  independently verified fallback.

## Repository controls

- GitHub Issues and Discussions are disabled. No public Issue is an active
  support, feedback, or backlog item.
- `SUPPORT.md`, private vulnerability reporting, and reviewed pull requests
  define the public paths.
- Vulnerability alerts, Dependabot security updates, secret scanning, and push
  protection are enabled.
- The main ruleset rejects deletion and non-fast-forward updates, requires
  linear history, and requires the publication-critical CI checks.
- The `v*` tag ruleset rejects release-tag deletion and non-fast-forward
  updates.

## Evidence boundaries at review time

The review did not observe an account-level signing identity, an audible
VoiceOver or NVDA review, or independent adoption. These are evidence states,
not implementation backlog. Synthetic proof cannot establish them. Future
evidence may be recorded when it exists; no public task is open for it.

## Lifecycle boundary

This review proves public source, release, proxy distribution, and a hosted
synthetic deployment. It does not establish an announcement, launch,
independent adoption, active use, retention, or revenue.
