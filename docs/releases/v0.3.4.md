# Nicos Catalog v0.3.4

## Main result

Nicos Catalog v0.3.4 is a compatible maintenance patch. It updates the
supported dependency set, rebuilds the embedded Explorer, and extends public
continuous integration to the documentation site.

## Added

- Continuous integration checks and builds the Astro documentation site.
- Publication tests verify the pinned pnpm version across the Explorer,
  documentation site, Makefile, and workflow.
- Publication tests verify dependency monitoring for both pnpm projects.

## Changed

- The Go YAML module, Explorer dependencies, documentation dependencies, and
  GitHub Actions are updated to compatible current versions.
- The embedded Explorer is rebuilt from the reviewed dependency lockfile.
- The Explorer uses TypeScript 7. The documentation site keeps TypeScript 6,
  which is the major supported by its Astro toolchain.

## Fixed

- The documentation site uses the repository-authored 404 page without also
  generating Starlight's default 404 route.
- Workflow pnpm setup now matches the exact package-manager pin in each Node
  project.

## Compatibility

- The module and CLI remain pre-1.0 SemVer.
- No exported Go API changed.
- `Index.SchemaVersion` remains 2.
- Explorer API and static manifest `schema_version` remain 1.
- Existing v0.3.x indexes remain valid.

## Security properties

The established boundaries remain in force: loopback-only live serving, a
closed public projection for static export, fixed response limits, no
third-party Explorer requests, no write command in HTTP or MCP, and restrictive
response headers in Cloudflare Pages exports.

## Install

```sh
go install github.com/nstranquist/nicos-catalog/cmd/nicos-catalog@v0.3.4
nicos-catalog version --expect v0.3.4
```
