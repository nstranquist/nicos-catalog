This book is the user manual for the portable **nicos-catalog** module and CLI. Hosts inject a `Layout` and providers. The engine owns validation, the deterministic index, BM25 search, the typed graph, drift and reconcile, and a closed publication DTO.

It does not teach host-only `ndev` verbs.
